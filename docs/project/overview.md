# КиноСовет — рекомендательная система фильмов

Сервис подбирает фильмы на основе оценок пользователя. Пользователь ставит
просмотренным фильмам оценки от 0,5 до 5 звёзд, а ML-модель находит
непросмотренные фильмы, похожие на те, что ему понравились. Это помогает
быстро выбрать, что посмотреть, без долгого листания каталога.

Принцип работы: ML-модель превращает текстовое описание каждого фильма
(название, жанры, теги) в вектор чисел. У похожих фильмов векторы близки,
поэтому сервис рекомендует фильмы, ближе всего к высоко оценённым.

Основные пользователи:

- зритель;
- администратор каталога фильмов.

Основные функции:

- формирование персональной подборки фильмов;
- просмотр последней подборки;
- просмотр карточки фильма.

## Комплект документации

1. **Описание проекта** — для всех участников; объясняет назначение и границы сервиса.
2. **Требования** — для аналитиков и тестировщиков; фиксирует, что должна уметь система.
3. **Архитектура и диаграммы** — для разработчиков; показывает компоненты и их взаимодействие.
4. **Документация API** — для разработчиков фронтенда и мобильного приложения; описывает запросы и ответы.
5. **Документация ML-модели** — для ML-инженеров и заказчика; описывает модель, данные, ограничения и риски рекомендаций.
6. **Руководство пользователя** — для зрителей; объясняет, как оценивать фильмы и получать подборки.
