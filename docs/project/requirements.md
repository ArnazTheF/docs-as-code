# Требования

## User Stories

### US-01. Персональная подборка

Как зритель,
я хочу получить список фильмов, похожих на те, что мне понравились,
чтобы быстро выбрать, что посмотреть.

Критерии приёмки:

- подборка строится, если пользователь оценил не менее 5 фильмов;
- в подборке от 1 до 50 фильмов (по умолчанию 10), уже оценённых фильмов в ней нет;
- для каждого фильма показана степень сходства с вкусами пользователя;
- если оценок меньше 5, пользователь видит сообщение «Оцените ещё несколько фильмов».

### US-02. Последняя подборка

Как зритель,
я хочу снова открыть последнюю подборку,
чтобы вернуться к ней позже без повторного подбора.

Критерии приёмки:

- подборка сохраняется вместе с датой создания;
- при повторном открытии показывается тот же список в том же порядке;
- если подборок ещё не было, система сообщает «Подборок пока нет».

### US-03. Карточка фильма

Как зритель,
я хочу открыть информацию о рекомендованном фильме,
чтобы решить, стоит ли его смотреть.

Критерии приёмки:

- отображаются название, год выпуска и жанры;
- если фильма нет в каталоге, система сообщает «Фильм не найден».

## Use Case

### UC-01. Формирование персональной подборки

**Актор:** зритель

**Цель:** получить список рекомендованных фильмов.

**Предусловие:** зритель вошёл в систему и оценил не менее 5 фильмов.

**Основной сценарий:**

1. Зритель нажимает «Подобрать фильмы» и при желании выбирает жанры.
2. Система получает оценки зрителя из базы данных.
3. Система передаёт ML-модели описания высоко оценённых фильмов и фильмов-кандидатов.
4. ML-модель возвращает векторы описаний.
5. Система находит самые похожие непросмотренные фильмы и сохраняет подборку.
6. Зритель видит список фильмов со степенью сходства.

**Альтернативные сценарии:**

- 2а. Оценок меньше 5 — система предлагает оценить ещё несколько фильмов, сценарий завершается.
- 4а. Модель недоступна — система сообщает «Сервис временно недоступен, повторите позже».

**Результат:** подборка сформирована и сохранена, либо зритель получил понятное сообщение о причине отказа.
